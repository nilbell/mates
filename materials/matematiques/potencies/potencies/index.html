Potències

Definició: una potència aⁿ és el producte de la base a per ella mateixa n cops: aⁿ = a · a · … · a (n factors). Si n = 0 no hi ha cap factor: el producte no ha començat i només queda el punt de partida, el 1.

Dibuix

Cada dibuix només funciona amb algunes potències; si no encaixa, t'ho diu.

El patró que ho explica tot

Cada esglaó cap avall divideix entre la base. Així el 1 del exponent 0 surt sol.

Canvia els valors

Caça l'error: en cada ronda hi ha igualtats veritables i falses. Marca (clica) les falses i prem Comprova. Pots jugar contra rellotge.
Punts: 0
Parelles: gira dues cartes i troba cada potència amb el seu valor. Com menys moviments i temps, millor.
Duel amb daus: cada equip tira un dau de base (el blanc) i un d'exponent (el taronja). Abans de revelar-ho, cada equip calcula el valor de la seva potència. Guanya el punt qui té la potència més gran.
Creixement: amb potències, una cosa petita pot arribar a ser gegant molt ràpid. Mou les hores, prediu el resultat i compara-ho amb un creixement «normal».
Blau: creixement amb potències. Taronja: creix sempre el mateix cada hora.
